# About this collection

A practical security audit guide for LLM-powered systems. Ten sections covering the most common attack surfaces, audit questions to ask, specific tests to run, and mitigations that hold up under scrutiny.

## Sections

1. Direct Prompt Injection
2. Indirect Prompt Injection
3. Jailbreaks (Safety Bypass)
4. RAG Risks
5. Output Handling
6. Model Supply Chain
7. Training Data and Fine-Tuning
8. Agent Tool Abuse
9. Multimodal Models
10. Evaluation and Red-Teaming

## How to use

Walk through the sections relevant to your system. Each section has a checklist suitable for a written audit. For systems in production, plan to revisit annually — both threats and mitigations evolve.

This is not a substitute for a model card, a SOC 2 audit, or external red-teaming for high-stakes deployments. It's a working baseline.
